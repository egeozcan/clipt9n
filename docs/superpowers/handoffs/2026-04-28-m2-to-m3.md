## Open considerations from M2's final review (M3 should know)

1. **Slot 6 gate** — M2's `app.rs::slot_to_action()` returns `None` for slot 6 ("Custom prompt — M3."). M3's first wiring change is to map slot 6 to *opening the custom prompt window* (not directly to `Action::Custom`, which needs the user's instruction first). The state machine likely grows a 4th state, `EnteringCustom`, before transitioning to `Translating`.
2. **Hotkey while Translating is currently ignored** — M2's `app.rs::drain_channels()` no-ops hotkey events while in `AppState::Translating`. M3's translating overlay has a Cancel button; if hotkey-during-translation should re-summon (cancel + re-show), revisit this in `drain_channels`.
3. **Clipboard-write failure on Ok path is silent** — M2's `handle_translation_done` logs but doesn't toast on `cb.write_text` error (the Err path DOES toast). Asymmetric. Consider unifying in M3.
4. **Bundled fonts still deferred to M8** — egui's default Hack/Ubuntu look fine but aren't Inter/JetBrains Mono. Don't try to fix this in M3.
5. **macOS Accessibility permission attaches to the parent process** — when running from terminal during dev, the *terminal* gets the permission, not the clipt9n binary. For distribution we'll bundle to a `.app` in M8. Don't try to fix this in M3.
6. **`with_visible(false)` is flaky on macOS** — M2 works around by re-asserting `ViewportCommand::Visible(matches!(state, AppState::Showing))` every frame in `update()`. If M3 introduces additional viewports (e.g., custom prompt window or translating overlay as separate viewports), each needs the same defensive pattern. **Recommendation: paint these as additional egui windows inside the same viewport rather than spawning new viewports** — simpler lifecycle, no `Visible(false)` hack needed per surface.
7. **ScrollArea inside the prompt window is mostly inert at 470px height** but defends against M3 adding more content (e.g., a glossary chip strip during M4). Don't remove it.
8. **Reduced-motion query** is M3's first OS-specific addition since M2 — goes in `src/platform/macos.rs` as a new trait method, with no-op defaults on Linux/Windows. Follow the pattern from `ensure_hotkey_permissions`.
